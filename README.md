# NetGuard IDS

Hybrid network intrusion detector (Isolation Forest + Random Forest, fused by a logistic meta-learner),
served as a Flask API with a small dashboard.

    train.py -> models/*.pkl + reports/EVAL.md
      -> predict_api.py (/predict, /predict_csv, /explain, /metrics)
      -> templates/dashboard.html (/dashboard)

## Results (CIC-IDS2017, Friday captures)

Headline: **PortScan, time-ordered test: attack-class F1 0.88 (95% bootstrap CI 0.85-0.91)**:
269 of 338 scans caught, 2 false alarms in 23,567 normal flows.

| Dataset | Split | F1 (95% CI) | Attacks caught | False alarms |
|---|---|---|---|---|
| PortScan | time-ordered | 0.88 (0.85-0.91) | 269 / 338 | 2 / 23,567 |
| PortScan | random | 0.99 | 385 / 391 | 0 |
| Botnet | random | 0.91 (0.88-0.93) | 238 / 287 | 0 |
| Botnet | time-ordered | 0.00 | 0 / 378 | 4 |

Random splits flatter this data: near-identical flows land in both train and test. The time-ordered split
(train on the earliest 60% of the file, test on the latest 20%, threshold tuned on the middle 20%) is the
number to trust. It shows scans generalize across time, but **botnet detection does not transfer to later
sessions**; the botnet model mostly memorizes sessions it saw in training. Full reports: `reports/EVAL.md`
and `reports/EVAL_chrono.md`, regenerated by `train.py` and `train.py --chrono`.

## Run
    pip install -r requirements.txt
    python train.py dataset/Portscan-Friday-no-metadata.csv            # random split, saves models
    python train.py dataset/Portscan-Friday-no-metadata.csv --chrono   # time-ordered eval, no model overwrite
    python app.py                                                      # http://localhost:5000/dashboard

## "Why flagged"
`/explain` ranks the 3 features furthest from the normal-traffic profile (deterministic). If `ANTHROPIC_API_KEY`
is set, an LLM only rephrases those facts in 2 sentences; otherwise a template is used. The LLM never decides
the verdict and sees no raw traffic.

## Limits
Benchmark CSVs, one dataset, one seed, not live traffic. Botnet detection fails time-ordered evaluation.
Live capture (`capture.py`) is local-only and not part of the evaluated system.
